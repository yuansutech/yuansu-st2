ABOUT

关于 Yuansu 生态

Yuansu 是一组独立的、开源的数字工具集合， 涵盖论坛社区、联机工具等方向。

所有服务都部署在 GitHub Pages 平台上， 没有中心服务器，没有账号体系，没有广告。

它本质上是一组"打开即用"的网页小工具， 只是为了方便，把它们汇总到了一个页面里。
  • 全部服务开源，代码可查
  • 无需注册，打开即用
  • 数据自己掌控，不上传第三方服务器
  • 国内 / 海外多入口，访问可选
  • 持续更新，废弃项目保留归档
  • 无广告、无追踪、无弹窗

FAQ

常见问题

Yuansu 是什么？
Yuansu 是一组独立的、开源的数字工具集合，目前包含元素论坛和联机内网穿透工具。所有服务都部署在 GitHub Pages 平台上，没有中心服务器。
需要注册账号吗？
大部分服务无需注册，打开即用。元素论坛支持匿名浏览和发帖，联机工具也不需要注册 Yuansu 账号。
服务是免费的吗？
全部免费。所有服务都基于免费平台部署，没有付费墙，没有广告，没有隐藏收费。
数据安全吗？
所有数据都直接与 GitHub 等平台交互，不经过 Yuansu 的服务器（因为没有服务器）。联机工具基于 Cloudflare 隧道，数据点对点传输。
为什么访问速度不一样？
不同服务的部署平台相同（GitHub Pages），但国内和海外的访问速度会有差异。可以根据网络环境选择合适的时间访问。
会一直维护吗？
活跃服务会持续更新。如果某个服务因为平台限制无法继续，会保留记录或迁移到新的地址。
可以贡献代码吗？
欢迎。所有服务都是开源的，可以在 GitHub 上找到对应仓库，提交 Issue 或 PR。

准备好开始了吗？

无需注册，无需下载，打开浏览器就能用。先从论坛或联机工具开始吧。
